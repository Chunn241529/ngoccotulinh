Thả ảnh lá bài vào thư mục này rồi refresh trang. Không cần sửa code.

Quy ước tên file (phần đầu tên quyết định loại lá):
  role-<gì cũng được>.png     -> lá Role   (viền vàng)
  feature-<...>.png           -> lá Tính năng (viền ngọc)
  token-<...>.png             -> texture cho token 3D (không thành lá)

Ví dụ:  role-01-guard.png, role-alchemist.jpg, feature-strike.png, token-blood.png

- Ảnh nên theo tỉ lệ 2.5 : 3.5 (vd 750x1050, 1000x1400). Tỉ lệ khác vẫn chạy,
  ảnh sẽ được crop kiểu "cover" cho vừa khung.
- PNG/JPG/WEBP/AVIF đều được. Tối đa 12 lá + 6 token.
- Token mặc định: 1-3 token mỗi lá, vẽ tự động nếu không có ảnh token.
- Thư mục trống -> cả bộ bài được vẽ procedural, vẫn chạy đẹp.
